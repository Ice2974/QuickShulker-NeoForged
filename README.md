# QuickShulker NeoForged

**中文** | [English](README_en.md)

QuickShulker NeoForged 是 `QuickShulker` 的非官方 Forge / NeoForge 移植版，目标是在不偏离原作核心体验的前提下，为现代 Forge 1.20.1 与 NeoForge 1.21.1 提供稳定可用的 quick-open 能力。

## 支持版本

| 平台 | 版本 | 状态 |
| --- | --- | --- |
| Forge | 1.20.1 | 维护中 |
| NeoForge | 1.21.1 | 维护中 |
