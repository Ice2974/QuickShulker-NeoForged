# Documentation

本目录用于存放当前维护文档、发布文档和历史归档资料。

## 目录结构

- `releases/`
  当前版本的发布说明和发布准备文档。
- `archive/stages/`
  历史阶段报告、旧实现记录和旧排坑记录。

## 查找建议

- 当前开发规则、工程边界和 Agent 协作约束，请看根目录 `AGENTS.md`。
- 面向玩家和发布页面访客的说明，请看根目录 `README.md`。
- 需要了解当前版本发布准备情况时，优先查看 `releases/` 下对应版本文档。
- 需要追溯历史实现背景时，再查看 `archive/stages/`。
