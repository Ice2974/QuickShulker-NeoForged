# 文档目录说明

本目录用于存放当前仍有效的发布文档，以及保留历史实现过程的归档文档。

## 当前文档

`docs/` 根目录只应保留当前维护、发布准备或状态判断仍需要使用的文档。

当前应优先阅读的文档包括：

- `README.md`：本目录结构说明
- `release-0.1.0.md`：当前发布验证与发布准备状态

## 历史文档

较早阶段的开发报告、实现记录、排坑说明和旧路线文档统一放在：

- `archive/stages/`

`docs/archive/` 下的文档仅作为历史记录保存，可用于回溯设计背景、迁移思路和排坑过程，但不再作为当前行为合同，也不应作为判断当前实现状态的唯一依据。

## 当前状态判断依据

判断项目当前状态时，应优先参考：

- 源码
- 当前发布文档，例如 `docs/release-0.1.0.md`
- 维护者或用户本次任务的明确要求

如果归档文档与当前源码或当前发布文档不一致，应将归档文档视为历史背景，并优先修正当前面向维护与发布的文档，而不是继续沿用旧阶段记录。
