# Bootstrap Skeleton

Current repository scaffold:

- `common`: shared Java-only constants and bootstrap helpers
- `versions/forge-1.20.1`: Forge 47.x entrypoint and Forge metadata
- `versions/neoforge-1.21.1`: NeoForge 21.x entrypoint and NeoForge metadata

This stage only establishes a buildable multi-module skeleton. QuickShulker gameplay features, menus, networking, configs, and keybindings are intentionally not implemented yet.
