# 阶段 7A：双平台全量回归与数据安全专项测试清单

> 历史开发记录：本文档记录早期阶段实现过程，不再作为当前实现状态的唯一依据。当前状态请以源码、README 和 `docs/release-0.1.0.md` 为准。


本阶段不新增功能，目标是对 stage-6C 之前已经接入的 quick-open 能力做回归验证，并重点排查：

- 物品复制
- 物品丢失
- 幽灵物品
- 潜影盒错误写回
- 切换打开时 A 内容写回到 B
- 误拦截原版放置 / 方块交互 / 实体交互
- 宿主锁定遗漏

## 执行原则

- 每项测试都分别覆盖 Forge 1.20.1 与 NeoForge 1.21.1。
- 每项测试尽量分别在单人与本地专用服务端环境执行。
- 能区分生存模式与创造模式的项目，两个模式都要覆盖。
- 若某项失败，先记录宿主类型、触发方式、宿主槽位、是否处于切换打开，再回查服务端日志。

## Forge 1.20.1

### 启动与安装

- 单人存档启动
- 本地 Forge 专用服务端启动
- 客户端 + 服务端双端安装

### 宿主类型

- `shulker_box`
- `ender_chest`
- `crafting_table`
- `stonecutter`
- `anvil`

`shulker_box` 人工测试要求：

- 至少覆盖普通潜影盒 + 多个染色潜影盒变体，不要只测未染色潜影盒
- 可以不要求 17 种潜影盒都跑完整矩阵，但发布前建议把 17 种变体都至少做一轮基础打开 / 关闭 / 保存测试

### 宿主位置

- 主手
- 副手
- 热栏
- 主背包
- 背包界面悬停

### 输入入口

- 无界面手持快捷键
- 无界面手持右键
- 背包内快捷键
- 背包内右键

### 会话与切换

- 同一宿主重复打开被拒绝
- 不同宿主切换打开成功
- 切换前旧 session 正常收尾
- 快速切换时不出现第二个互不相通的容器副本
- `Esc` 关闭
- `E` 关闭

### 数据安全

- 潜影盒放入物品后关闭，再次打开内容正确
- 潜影盒取空后关闭，再次打开仍正确保存为空
- 普通潜影盒与多个染色潜影盒变体都能基础打开、关闭并正确保存
- 末影箱使用玩家真实 `EnderChestInventory`
- 工作台 / 切石机 / 铁砧不向宿主写回菜单内容
- 铁砧损耗只作用于宿主铁砧物品
- 宿主失效后不把内容写回错误目标
- 快速关闭 / 切换后不出现物品丢失

### 宿主锁定与交互

- 普通物品切副手仍保留原版行为
- 副手宿主不能被换走
- 左键不能拿起宿主
- 右键不能拿起宿主
- `shift-click` 不能移走宿主
- 数字键交换不能移走宿主
- `Q` 不能丢弃宿主
- `F` 不能换走宿主
- `PICKUP_ALL` 不会收走宿主
- `QUICK_CRAFT` 不会拖拽影响宿主

### 原版交互不被误抢

- 对可放置位置右键时优先原版放置
- 对可交互方块右键时优先原版交互
- 对可交互实体右键时优先原版交互
- 打开请求不合法时不会取消原版行为

### 模式专项

- 生存模式无幽灵物品
- 生存模式无错误回滚
- 创造模式不复制
- 创造模式无异常容器副本

## 追加高风险场景

- 宿主在打开期间被外部移走
- 宿主在打开期间被外部替换
- 宿主在打开期间堆叠数量变化
- 菜单内从 A 宿主切换到 B 宿主
- 对当前同一宿主连续右键 / 连续快捷键
- 快速关闭菜单
- 玩家死亡
- 玩家掉线
- 玩家切维度
- 客户端和服务端配置不一致

## 记录建议

- 记录失败平台、宿主类型、宿主位置、触发入口、是否单人/联机、是否生存/创造。
- 记录是否涉及 same-host 重复打开，还是 different-host 切换打开。
- 若涉及潜影盒写回异常，记录旧宿主与新宿主分别是什么。
